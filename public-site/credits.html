Mauve is by smoothee. Its archive is fetched directly from the creator's GameBanana download endpoint when a player starts the game; it is not mirrored in this repository. Please read the creator's license on the map page.

Mauve declares these required helper mods. Their archives are also fetched directly from GameBanana at launch, not stored in this repository:

  • Brokemia Helper by Brokemia
  • Maddie's Helping Hand (MaxHelpingHand) by maddie480
  • Isa's Grab Bag of Mechanics by IsaGoodFriend
  • Contort Helper by MunTheory
  • VivHelper by Viv

The base-game package is fetched from the separate a-faus/celeste-browser project. This page does not contain any player's save files. Progress remains in browser-local storage and is shared with compatible a-faus Celeste pages only within the same browser profile on this device; there is no account or cloud synchronization.
