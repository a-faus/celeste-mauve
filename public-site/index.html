Your Celeste saves are kept

Mauve shares the same browser-local save folder as your Celeste and Randomizer pages. Use the same Chrome or Edge profile and close any other Celeste game tab before opening this one. Saves are not bundled here or uploaded to GitHub.

Browser storage does not sync between computers or browser profiles. Export a backup from the game's folder button before clearing site data or switching devices.

Only Mauve and what it needs

The first launch prepares the base game with a prepatched, browser-compatible Everest runtime, then installs Mauve and only the five helpers declared by Mauve's own manifest. No Randomizer, Spring Collab, Gravity Helper, or unrelated map packs are installed. Allow about 1.5 GB of browser storage and keep the tab open during setup.

Requires a current desktop Chrome or Edge browser with site storage and service workers enabled. The initial setup may take several minutes.
